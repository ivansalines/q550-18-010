# Scientific report (pre-server)

Q550 v18.52h is an executable post-crest extension. The previous v18.52g report establishes the first eight convexity sign reversals and no detected return through xi=0.8. It also reports a sampled `I/P` crest followed by a decline. This release contains no new physical result: the extension must run against the original v18.51s source on the user's server. See `results/SCIENTIFIC_REPORT_SERVER.md` after execution, together with `results/report.json`, for signed results and numerical limitations.
