1. **Integrity gate**: archived h generator source and every available source /
   output hash must match; h must have authentic refined 10D results. Embedded
   g ancestry and external s lineage must match their recorded SHA digests.
2. **Continuity gate**: global xi starts at 1.6, no phase reset; 11D material
   clock is monotonic; both 5D physical vectors and scalar D/G agree with h at
   the time seam within explicitly tested finite tolerance.
3. **Kinematic gate**: C=P-I, D=0.5||q||^2, G=q.v. Independently check the
   derivatives and the radial/tangential velocity decomposition.
4. **Refinement gate**: repeat all reference and kick trajectories at stricter
   tolerances and smaller max step. New sign-changing G/C events must survive
   independent re-bracketing. Report lack of brackets rather than invent events.
5. **Classification**: G negative-to-positive -> local D minimum; G
   positive-to-negative -> local D maximum; C zero alone -> curvature reversal.
   Without G zero, report *no detected return/minimum in finite horizon*.
6. **No false closure**: a minimum of D, a decline of ||q||, an angular
   excursion, or a similar 2D projection is not an identical 5D/10D physical
   state and not a certified closed orbit or material memory mechanism.
7. **Stop on failed checks**: preserve results for diagnosis and withhold
   physical promotion. Numerical event bracketing is not an interval enclosure.
