# Q550 v18.51t — Source-to-Response Green Transport & Radial–Azimuthal Causality Audit

A reproducible, genealogically anchored first-variation attribution for the historical nonlinear 10D Q550 field.

## Run on the research server

```bash
cd /root/elab1/hysteresis
unzip q550_source_to_response_green_transport_radial_azimuthal_causality_v18_51t_bundle.zip
cd q550_source_to_response_green_transport_radial_azimuthal_causality_v18_51t_bundle
set -o pipefail
OPENBLAS_NUM_THREADS=1 PYTHON_BIN=python3.13 bash run_on_server.sh \
  2>&1 | tee ../v18_51t_server.log
```

The runner authenticates the v18.51s sendback, runs a standalone known-solvable Green/linear-source synthetic test, stages the verified original historical model through the s→r→q ancestry, integrates separately sourced physical-variation equations for both seed families, compares against an independently integrated fundamental Green representation, verifies physical secant and parent variational consistency, validates results, generates output hashes, and packs a sendback ZIP alongside this directory.

## Research outputs

- `results/report.json`: numerical findings, checks, limitations, values for both seeds.
- `results/green_transport_attribution_ledger.csv`: 1026 records with signed source→radial/azimuthal entries, cross terms, phase and transverse splits, and recomposition errors.

- `results/source_to_response_green_radial_azimuthal_transport.png`: per-seed channel plot and independent physical comparison.
- `results/LOCAL_CACHED_PRECHECK.json`: source-and-trajectory statistics from authenticated v18.51s alone; **not** the new Green audit.

## Scientific interpretation

A third `rest` channel is always included to prevent discarded source components. The two original κ₀ trajectories in the r genealogy are genuine nonlinear solutions, not surrogates. All reports, code comments, and source documents are in English.

## Requirements

Python 3.13 on the research server; NumPy, SciPy, and Matplotlib. Set `OPENBLAS_NUM_THREADS=1` to avoid unnecessary threaded BLAS overhead. All original embedded source inputs are contained in `inputs/` with SHA-256 provenance. Files in `results/` are generated by the supplied scripts.

Use `python3.13 scripts/run_audit.py --mode cached` only for the parent authentication precheck; **this is not a substitute for the full mode**.

## Lightweight download fallback

If the complete ancestral ZIP cannot be downloaded, use the additional `..._source_only_bundle.zip`, which preserves the same full root folder and all scripts/results but omits the already-delivered large `v18.51s` sendback. Copy your existing exact parent server archive to `inputs/q550_parameter_sensitivity_transport_transverse_posture_attribution_v18_51s_bundle_server_sendback.zip` **before** running, or source authentication will fail by design.
