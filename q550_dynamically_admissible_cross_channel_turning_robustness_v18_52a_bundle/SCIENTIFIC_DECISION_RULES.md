# Scientific decision rules — Q550 v18.52a

**Never conflate a completed/valid numerical audit with a positive robustness finding.**

- Numerical success requires authenticated historical parent ZIPs, finite structural jets, consistent kappa source differentiation, channel sum closure, wedge-budget reconstruction, independent midpoint replay and grid refinement. Green comparison adds an independent numerical control unless skipped explicitly.
- Scientific cross-dominance is measured by the *signed* inequality `mixed + self_v2 + self_omega2 > 0`, using the common total response norm in the denominator, on every qualified sampled section.
- Scientific total response orientation is measured separately: `omega_total > 0` on the same physical branches. The remaining model source channels are not discarded.
- The original model source support (`v2`, `omega2`, `other`) is preserved. No rotated/recoded channels are regarded as an independent physical perturbation.
- The central kappa0 value and both historical endpoints must be analyzed on both independently prepared seeds. Do not infer a continuous interval theorem merely because three sampled parameter points pass.
- If any scientific condition fails, report that fact while retaining the numerical PASS if all numerical integrity/accuracy checks succeed.
- If jet interpolation or kappa-derivative controls fail, the numerical check must FAIL, and no positive scientific certificate may be claimed.
- Never claim physical return, generic material memory or global stability from `xi <= 0.20`.
